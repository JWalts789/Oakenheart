# Oakheart Online Design Hub

Static design dashboard for the Oakheart Online prototype. The game is currently a single-player Unreal Engine 5.8 action RPG in Sweetbriar, Verdantia. MMO networking, parties, and a persistent world are future work.

The published `project-snapshot.json` is the reference dataset for a new visitor. Dashboard edits are saved only in that visitor's browser; GitHub Pages does not share or sync them. **Export JSON** backs up a browser workspace. **Merge JSON Import** adds IDs that are absent and leaves existing entries untouched. **Replace JSON** replaces the browser workspace with a full export. **Load latest project snapshot** replaces it with the published dataset. Export first if local edits matter.

The repository name and URL retain the old `Oakenheart` spelling so existing links keep working. The visible game name is **Oakheart Online**.
